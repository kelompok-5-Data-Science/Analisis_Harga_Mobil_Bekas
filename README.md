Analisis Harga Mobil Bekas

Proyek ini bertujuan untuk menganalisis dan memprediksi harga mobil bekas menggunakan Machine Learning. Prediksi dilakukan berdasarkan tahun produksi, kilometer tempuh, merek mobil, dan jenis transmisi.

Tujuan
1. Mengetahui karakteristik data mobil bekas.
2. Menganalisis hubungan tahun dan kilometer tempuh dengan harga mobil.
3. Membuat model prediksi harga mobil bekas.
4. Mengevaluasi performa model menggunakan MAE, RMSE, dan R².

Tahapan Pengerjaan
1. Memuat dataset menggunakan Pandas.
2. Memeriksa nilai kosong dan tipe data.
3. Melakukan eksplorasi data dan visualisasi grafik.
4. Membagi data menjadi data latih dan data uji.
5. Melatih model Random Forest Regressor.
6. Mengevaluasi hasil prediksi model.

Tools yang Digunakan
- Python
- Google Colab
- Pandas dan NumPy
- Matplotlib dan Seaborn
- Scikit-learn

File Proyek
- Analisis_Harga_Mobil_Bekas.ipynb: kode analisis dan model Machine Learning.
- data_mobil_yang_dibersihkan.csv: dataset mobil bekas.
- README.md: dokumentasi proyek.
